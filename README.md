# Glitter-Player

Glitter Player is a lightweight media player built with Python, PyQt6, and VLC. It allows users to play audio files with a simple, user-friendly interface.

## Features
- Play audio files
- Customizable interface (different themes)
- No ads
- Aesthetic, simple and creative interface

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/kaiha1/glitter-player.git
   cd glitter-player
   
2. Install the required Python packages:
pip install pyqt6 python-vlc

3. Install VLC media player (if you don't have it installed already)
--for Windows/Mac: download from https://www.videolan.org/
--for Linux (Debian/Ubuntu): sudo apt install vlc

4.run the app:
python main.py

⚠️ VLC must be installed on your system for Glitter Player to work.
